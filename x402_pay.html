⚡ SubnetROI runs on x402

Everything on this site is sold over plain HTTP using the x402 payment protocol — the open standard built on HTTP 402 Payment Required. No accounts, no subscriptions, no API keys. Any wallet (or AI agent with a wallet) pays per request with a single signature, and settles in USDC on Base.

Prices: $1.00 USDC for API reads and portfolio valuations — $3.00 for deep-dive research reports. One protocol, no billing relationship.

Why x402

SubnetROI sells information — ROI data, research reports, ebooks, portfolio valuations. Information wants a micropayment rail that is built into the web, not bolted on after. x402 re-activates the long-reserved 402 Payment Required status code:

  1. A client requests a resource without payment.
  2. The server replies 402 with a PAYMENT-REQUIRED header — price, asset, receiving wallet, network.
  3. The client signs the authorization with its wallet (gasless, EIP-3009 / Permit2) and retries with a PAYMENT-SIGNATURE header.
  4. A facilitator verifies and settles the transfer on-chain; the server returns 200 + the resource.

For you as a builder: no account creation, no credit card, no monthly commitment, no KYC — machines transact like they breathe. That is the point.

Try it — one request

There is no API key. Copy this into curl with x402 installed, or use the SDK:

# 1. discover the payment requirement
curl -s -D - -o /dev/null https://subnet-roi-api.mentatdev.workers.dev/v1/x402/checkout/api:roi-top
#     → HTTP/2 402 · PAYMENT-REQUIRED: <base64 requirements: $1 USDC → 0x7d47…CC838>

# 2. pay with your wallet (SDK does this)
pip install x402
#    npm i @x402/fetch @x402/evm

# 3. retry with the signed header → 200 + live top subnets
